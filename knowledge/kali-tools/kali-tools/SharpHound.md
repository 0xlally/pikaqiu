# SharpHound

**Category**: Active Directory, Kerberos, LDAP, and SMB enumeration

**Purpose**: Windows AD graph collector for BloodHound.

**When to use**: Use when a Windows domain, SMB, LDAP, Kerberos, domain credentials, or internal Windows hosts are discovered.

## Paths
- `/opt/windows-tools/SharpHound`

## First Commands
- `ls -la /opt/windows-tools/SharpHound`

## Notes
Windows-native/source tool; transfer/build/use on a Windows host when needed.
