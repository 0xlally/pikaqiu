# arjun

**Category**: Web discovery, fuzzing, and vulnerability checks

**Purpose**: Discover hidden HTTP parameters and undocumented request fields.

**When to use**: Use when the target exposes HTTP/HTTPS, APIs, parameters, directories, virtual hosts, known products, or reflected input.

## Commands
- `arjun`

## First Commands
- `arjun -u http://TARGET/path -m GET,POST`

## Notes
Good after finding an endpoint with missing behavior or IDOR-like input.
