# wireshark

**Category**: Packet capture and protocol analysis

**Purpose**: GUI packet analysis when display forwarding is available.

**When to use**: Use when traffic evidence, protocol debugging, credentials in transit, or pcap analysis matters.

## Commands
- `wireshark`

## First Commands
- `wireshark -h`

## Notes
Usually use tshark instead inside the sandbox.
