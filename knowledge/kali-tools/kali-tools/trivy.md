# trivy

**Category**: Cloud, container, dependency, and Kubernetes auditing

**Purpose**: Scan container images, filesystems, IaC, and dependencies for vulnerabilities and secrets.

**When to use**: Use when cloud credentials, container images, Kubernetes endpoints, manifests, or filesystem dependency risk are discovered.

## Commands
- `trivy`

## First Commands
- `trivy fs .`
- `trivy image IMAGE`
- `trivy config .`

## Notes
Use after finding source code, Dockerfiles, manifests, or image names.
