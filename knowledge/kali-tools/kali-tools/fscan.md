# fscan

**Category**: Web discovery, fuzzing, and vulnerability checks

**Purpose**: Fast intranet host, port, service, and weak credential discovery.

**When to use**: Use when the target exposes HTTP/HTTPS, APIs, parameters, directories, virtual hosts, known products, or reflected input.

## Commands
- `fscan`

## First Commands
- `fscan -h TARGET_CIDR -o fscan.txt`

## Notes
Use for internal network ranges after pivoting or when multiple private IPs are discovered.
