# searchsploit

**Category**: Web discovery, fuzzing, and vulnerability checks

**Purpose**: Search the local Exploit-DB mirror for known product/version exploits.

**When to use**: Use when the target exposes HTTP/HTTPS, APIs, parameters, directories, virtual hosts, known products, or reflected input.

## Commands
- `searchsploit`

## First Commands
- `searchsploit PRODUCT VERSION`
- `searchsploit -m EXPLOIT_PATH`

## Notes
Use after fingerprinting product and version; prefer reading exploit source before running.
