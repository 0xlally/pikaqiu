# powerview

**Category**: Active Directory, Kerberos, LDAP, and SMB enumeration

**Purpose**: Python PowerView-style AD enumeration for users, groups, ACLs, computers, and trusts.

**When to use**: Use when a Windows domain, SMB, LDAP, Kerberos, domain credentials, or internal Windows hosts are discovered.

## Commands
- `powerview`

## First Commands
- `powerview -h`
- `powerview DOMAIN/USER:PASS@DC_IP --help`

## Notes
Use when LDAP/AD object relationships matter.
