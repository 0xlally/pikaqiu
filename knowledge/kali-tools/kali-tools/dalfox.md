# dalfox

**Category**: Web discovery, fuzzing, and vulnerability checks

**Purpose**: Find and validate reflected, stored, and parameter-based XSS.

**When to use**: Use when the target exposes HTTP/HTTPS, APIs, parameters, directories, virtual hosts, known products, or reflected input.

## Commands
- `dalfox`

## First Commands
- `dalfox url 'http://TARGET/search?q=FUZZ'`
- `dalfox file urls.txt`

## Notes
Confirm exploitable output manually; use with collected URLs and parameters.
