# kube-hunter

**Category**: Cloud, container, dependency, and Kubernetes auditing

**Purpose**: Kubernetes cluster exposure and weakness discovery.

**When to use**: Use when cloud credentials, container images, Kubernetes endpoints, manifests, or filesystem dependency risk are discovered.

## Commands
- `kube-hunter`

## First Commands
- `kube-hunter --remote HOST`
- `kube-hunter --cidr CIDR`

## Notes
Use only when Kubernetes targets are in authorized scope.
