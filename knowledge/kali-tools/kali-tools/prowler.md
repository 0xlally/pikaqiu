# prowler

**Category**: Cloud, container, dependency, and Kubernetes auditing

**Purpose**: Cloud security auditing for AWS, Azure, GCP, and Kubernetes.

**When to use**: Use when cloud credentials, container images, Kubernetes endpoints, manifests, or filesystem dependency risk are discovered.

## Commands
- `prowler`

## First Commands
- `prowler -h`
- `prowler aws --profile PROFILE`

## Notes
Requires valid cloud credentials or environment configuration.
