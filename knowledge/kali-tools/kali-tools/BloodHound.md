# BloodHound

**Category**: Active Directory, Kerberos, LDAP, and SMB enumeration

**Purpose**: AD attack path analysis and/or Python data collector.

**When to use**: Use when a Windows domain, SMB, LDAP, Kerberos, domain credentials, or internal Windows hosts are discovered.

## Commands
- `bloodhound`
- `bloodhound-python`

## First Commands
- `bloodhound-python -h`

## Notes
Use BloodHound GUI where available; use bloodhound-python for collection from Linux.
