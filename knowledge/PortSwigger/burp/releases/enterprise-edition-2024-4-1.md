# Enterprise Edition 2024.4.1

Source: https://portswigger.net/burp/releases/enterprise-edition-2024-4-1
Fetched: 2026-06-28T09:16:20.517552+00:00

This release of Burp Suite Enterprise Edition updates Java support, boosts scanner performance, and fixes some bugs.

Java 21.0.3 support

We've updated Burp Suite Enterprise Edition to support Java 21.0.3, enhancing both performance and security.

Bug fixes

We fixed a performance issue in Burp Scanner, enabling more efficient processing of large responses.

We fixed a bug that was causing a validation issue in Oracle DB 19c databases.
