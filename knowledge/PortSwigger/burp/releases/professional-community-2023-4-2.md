# Professional / Community 2023.4.2

Source: https://portswigger.net/burp/releases/professional-community-2023-4-2
Fetched: 2026-06-28T09:16:42.953952+00:00

This release upgrades Burp's browser and fixes a bug in Burp Scanner.

Browser upgrade

We have upgraded Burp's built-in browser to Chromium 112.0.5615.137/138 for Windows, 112.0.5615.165 for Linux, and 112.0.5615.137 for Mac.

Bug fix

We have fixed a bug in Burp Scanner that caused issues when crawling some API definitions.
