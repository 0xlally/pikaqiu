# Professional / Community 2025.9.1

Source: https://portswigger.net/burp/releases/professional-community-2025-9-1
Fetched: 2026-06-28T09:16:55.619758+00:00

This release fixes a startup bug and upgrades Burp's browser to fix a critical CVE.

Bug fix

We've fixed a bug where Burp was failing to start correctly if the Bambda library contained a Bambda with a special character in its name.

Quality of life improvement

The custom scan check editor now shows a confirmation dialog when the escape key is pressed.

Browser upgrade

We've upgraded Burp's browser to Chromium 140.0.7339.133 (Mac), 140.0.7339.128 (Windows) and 140.0.7339.127 (Linux). For more information, see the

Chromium release notes.
