# Professional / Community 2024.3.1.4

Source: https://portswigger.net/burp/releases/professional-community-2024-3-1-4
Fetched: 2026-06-28T09:16:46.462443+00:00

This release upgrades Burp's built-in browser and fixes a bug with custom table columns.

Bug fix

We have fixed a bug whereby custom table columns stopped returning new values after encountering a null value. Null values are now calculated and displayed.

Browser upgrade

We have upgraded Burp's browser to Chromium 124.0.6367.118 for Windows, Linux, and Mac. This upgrade includes several security fixes, including one fix for a critical vulnerability. For more information, see the Chromium release notes.
