# Enterprise Edition 2024.3.2

Source: https://portswigger.net/burp/releases/enterprise-edition-2024-3-2
Fetched: 2026-06-28T09:16:20.556104+00:00

This release fixes a bug that stopped the "Copy to clipboard" function from working over HTTP.

We have also removed support for the MySQL external database version 5.7. We currently support version 8.3.0 and any earlier versions that are supported by MySQL.
