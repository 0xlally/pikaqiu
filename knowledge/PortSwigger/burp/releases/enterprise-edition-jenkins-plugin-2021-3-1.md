# Enterprise Edition Jenkins plugin 2021.3.1

Source: https://portswigger.net/burp/releases/enterprise-edition-jenkins-plugin-2021-3-1
Fetched: 2026-06-28T09:16:21.359957+00:00

This release provides several minor bug fixes, most notably:

Builds no longer fail if you don't manually select a site from the provided dropdown or if your site tree only contains a single site.

Error messages are now displayed correctly in newer versions of Jenkins.
