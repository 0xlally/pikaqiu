This release includes a Java upgrade and an update for Burp's built-in browser.

Java upgrade

Burp now uses Java 21.0.2, enhancing both performance and security.

Browser upgrade

We have upgraded Burp's browser to 124.0.6367.155 for Windows, Linux, and Mac. For more information, see the Chromium release notes.
