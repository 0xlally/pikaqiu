# Enterprise Edition 1.0.14beta

Source: https://portswigger.net/burp/releases/enterprise-edition-1-0-14beta
Fetched: 2026-06-28T09:16:15.626484+00:00

This release contains a number of bugfixes.

It also contains the following new features:

The Sites view now includes a progress bar for running scans.

Support for Jira server (on-premises).

The Sites search has an auto-complete drop-down.

Note: This is an incremental update to the v1.0 beta release. Please read the Enterprise Edition release announcement for full details.
