# Professional 2.0.20beta

Source: https://portswigger.net/burp/releases/professional-2-0-20beta
Fetched: 2026-06-28T09:16:29.699670+00:00

This release contains a number of bugfixes. This includes security fixes to the embedded Chromium browser. It is recommended that users of Burp 2.x update to this version as soon as possible.

Note: This is an incremental update to the Burp 2.0 beta release, and the same caveats apply. Please read the Burp 2.0 blog post in full before using this release.
