# Professional / Community 2024.1.1.5

Source: https://portswigger.net/burp/releases/professional-community-2024-1-1-5
Fetched: 2026-06-28T09:16:45.360416+00:00

This release fixes a bug with selecting items from the site map and upgrades Burp's browser to the latest version of Chromium.

Bug fix

We have fixed a bug whereby sometimes Burp was displaying an incorrect request / response pair when selecting items in Target > Site map. The site map now correctly displays the request and response for the selected item.

Browser upgrade

We've upgraded Burp's built-in browser to 1122.0.6261.94 for Mac/Linux and 122.0.6261.94/.95 for Windows. For more information, see the Chromium release notes.
