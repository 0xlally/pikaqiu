# Enterprise Edition 1.0.10beta

Source: https://portswigger.net/burp/releases/enterprise-edition-1-0-10beta
Fetched: 2026-06-28T09:16:15.240254+00:00

This release adds Jira integration. You can configure details of your Jira installation, and then generate Jira tickets from scan issues:

The initial implementation supports manual generation of tickets in a single Jira project. Our roadmap for the Jira integration includes:

The ability to configure different Jira installations or projects for different sites or sections of the sites tree.

The ability to auto-generate Jira tickets for new scan issues.

The release also adds reporting of the delta between recurring scans. When viewing the results of a recurring scan, Burp indicates when issues are new, resolved, repeated, or regressions:

The release also contains a number of bugfixes.

Note: This is an incremental update to the v1.0 beta release. Please read the Enterprise Edition release announcement for full details.
