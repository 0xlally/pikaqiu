# Professional / Community 2024.9.5

Source: https://portswigger.net/burp/releases/professional-community-2024-9-5
Fetched: 2026-06-28T09:16:49.674126+00:00

This release introduces a new setting which gives you more control over the Intruder side panel layout. We've also fixed a bug.

Intruder side panel layout

We've added the Default Intruder side panel layout setting, which enables you to configure the Intruder sidebar layout independently from other sidebars. This gives you more control over your Intruder workspace layout.

Bug fixes

We've fixed an issue on Windows where Intruder attacks wouldn't start if the attack configuration was copied from a previous tab with payload encoding enabled but no encoding characters specified.
