# Professional 1.3beta

Source: https://portswigger.net/burp/releases/professional-1-3beta
Fetched: 2026-06-28T09:16:23.701904+00:00

This release adds numerous new features. See the preview for full details, but here are the highlights:

Improved search, with regex, scope restrictions, dynamically updating results, etc.

Request annotation.

Fine-grained upstream proxy rules.

Automated content discovery.

Scripts and comment search.

New display filters.

Wizard for performing active scans of multiple items.

Manual testing simulator.

Exporting of request metadata in XML format.

Target analyser.

Have fun!
