# DAST 2026.5.2

Source: https://portswigger.net/burp/releases/dast-2026-5-2
Fetched: 2026-06-28T09:16:14.174529+00:00

This release enables you to set the Negotiate auth scheme and SPNEGO encoding options when you configure NTLM credentials for site configurations and upstream proxy settings.

These options are available for both NTLM v1 and NTLM v2, and match the options already available in scan configuration. This gives you consistent control over how Burp Scanner authenticates, wherever you set up your NTLM credentials.

For more information, see Configuring platform authentication and Configuring upstream proxy servers.

Bug fixes

We fixed an issue where scans were being incorrectly marked as failed for Cloud customers.
