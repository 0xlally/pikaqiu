# Professional / Community 2024.5.1

Source: https://portswigger.net/burp/releases/professional-community-2024-5-1
Fetched: 2026-06-28T09:16:47.939725+00:00

This release upgrades Burp's browser and fixes a bug with disk-based project files.

Bug fix

We fixed a bug with disk-based project files. If you had configured proxy settings in a previous version of Burp, they would reset if you opened the project in version 2024.5.

Browser upgrade

We have upgraded Burp's browser to Chromium 125.0.6422.112 for Windows, Linux, and Mac. This upgrade includes a security fix. For more information, see the Chromium release notes.
