# Professional / Community 2025.8.6

Source: https://portswigger.net/burp/releases/professional-community-2025-8-6
Fetched: 2026-06-28T09:16:55.454182+00:00

This release improves scanner error messaging, fixes a bug, and upgrades Burp's browser.

Quality of life improvements

We've improved error messaging for scan failures caused by recorded logins, making them easier to troubleshoot.

Bug fixes

We've fixed a bug that was causing floating inputs to create duplicate lists on pages with many clickables. This reduces unnecessary memory use on large pages.

Browser upgrade

We've upgraded Burp's browser to Chromium 140.0.7339.208 for Windows & Mac and 140.0.7339.207 for Linux. For more information, see the Chromium release notes.
