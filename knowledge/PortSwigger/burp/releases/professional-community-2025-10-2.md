# Professional / Community 2025.10.2

Source: https://portswigger.net/burp/releases/professional-community-2025-10-2
Fetched: 2026-06-28T09:16:50.593282+00:00

This release enhances Burp Scanner with extended OpenAPI 3.1 and early 3.2 support, improves the speed of the Proxy filter toggle and upgrades Burp's browser.

Improved OpenAPI compatibility

We've upgraded Burp Scanner to offer extended support for OpenAPI 3.1, and introduced early support for 3.2. That means fewer parsing errors and improved compatibility with newer API definitions.

Quality of life improvements

We've improved the speed of the filter toggle in Proxy > HTTP history and Proxy > WebSockets history. Turning the filter on and off now updates the view instantly.

Browser upgrade

We've upgraded Burp's browser to Chromium 142.0.7444.60 for Windows & Mac and Chromium 142.0.7444.59 for Linux. For more information, see the Chromium release notes.
