# Enterprise Edition 2024.3.1

Source: https://portswigger.net/burp/releases/enterprise-edition-2024-3-1
Fetched: 2026-06-28T09:16:20.439263+00:00

This release fixes an issue with Burp Suite Enterprise Edition failing to start correctly if you have an HTTP proxy server configured. We've also fixed some other bugs.

Bug fixes

We've fixed an issue with Burp Suite Enterprise Edition failing to start correctly if you have an HTTP proxy server configured.

If you have experienced this issue and disabled the proxy server, you may need to download the update from Burp Suite Releases and manually install it. For more information, see Updating standard deployments of Burp Suite Enterprise Edition.

Other bug fixes:

We've fixed an issue with downloading scanner updates.

We've fixed an issue with SCIM that occurs if you disable and then re-enable it.
