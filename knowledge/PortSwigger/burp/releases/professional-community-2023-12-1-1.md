# Professional / Community 2023.12.1.1

Source: https://portswigger.net/burp/releases/professional-community-2023-12-1-1
Fetched: 2026-06-28T09:16:41.646303+00:00

This release upgrades Burp’s browser and provides some minor UI improvements.

Browser upgrade

This release upgrades Burp’s built-in browser to Chromium 120.0.6099.199 for Mac and Linux, and 120.0.6099.199/200 for Windows. For more information, see the Chromium release notes.

Other improvements

When the event log and all issues panels contain new entries that you haven’t viewed yet, Burp now indicates this by adding a colored dot next to the relevant tab in the dock at the bottom of the window.

A blue dot indicates that Burp has identified new informational or low-severity issues.

A red dot indicates that Burp has identified a new medium or high-severity issue.
