# Professional / Community 2024.1.1.2

Source: https://portswigger.net/burp/releases/professional-community-2024-1-1-2
Fetched: 2026-06-28T09:16:45.157161+00:00

This release provides some performance improvements when proxying requests through Burp, as well as some minor bug fixes. Most notably:

We've fixed an issue that caused notes and highlights in the proxy history to be lost when closing a project file.

We've fixed an issue that prevented audit queue items from being presented correctly after reopening an existing project file.

We've fixed some issues with filtering and sorting of tables.
