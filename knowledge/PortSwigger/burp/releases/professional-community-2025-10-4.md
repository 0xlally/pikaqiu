# Professional / Community 2025.10.4

Source: https://portswigger.net/burp/releases/professional-community-2025-10-4
Fetched: 2026-06-28T09:16:50.861720+00:00

This release fixes an issue with saving custom detection methods in scan checks and upgrades Burp's browser.

Bug fixes

We've fixed an issue that caused custom detection method settings for individual scan checks to not save correctly.

Browser upgrade

We've upgraded Burp's browser to Chromium 142.0.7444.135 for Windows & Mac and 142.0.7444.134 for Linux. For more information, see the Chromium release notes.
