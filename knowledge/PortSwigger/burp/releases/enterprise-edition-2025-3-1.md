# Enterprise Edition 2025.3.1

Source: https://portswigger.net/burp/releases/enterprise-edition-2025-3-1
Fetched: 2026-06-28T09:16:21.215661+00:00

This release fixes the following bugs:

Users with permission to create sites for specific folders are no longer prevented from entering authentication information when they create a new site.

Users with permission to cancel scans can now delete bulk schedules from the Scheduled scans tab, as expected.
