Burp's AI features only run if you explicitly activate them. The AI settings page provides an additional safeguard to prevent you from accidentally using AI.

Select Disable AI features to disable all AI communication, including AI credit balance checks. When AI features are disabled, any AI-related options are grayed out in Burp and cannot be selected.
