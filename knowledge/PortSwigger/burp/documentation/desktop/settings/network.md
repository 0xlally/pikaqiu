The Network section in the Settings dialog enables you to configure:

Connections - General settings defining how Burp handles network traffic.

TLS - Settings related to the TLS protocols and certificates that Burp uses.

HTTP - Settings controlling how Burp processes HTTP traffic.

DNS - Settings for resolving domain names to IP addresses.
