Is Community Edition changing?

No. It's not going anywhere, and this change doesn't affect its features. Community Edition remains a key part of Burp Suite, and we're proud that hundreds of thousands of people use it to get started with web security testing.

Will this affect how I use Burp Suite?

The only changes are how Burp Suite is installed and an updated icon. Once installed, your experience is unchanged. Your configuration is migrated automatically, so you can pick up where you left off without interruption. If you have automation or scripts that reference previous versions of Burp Suite or the installer, you will need to update them.

How does this affect my license or account?

It doesn't. If you have an active license, you can continue using Burp Suite Professional without interruption. You can download your license key from the subscriptions page in your PortSwigger account if needed.

I'm an extension developer. What do I need to know?

The Burp Extender API hasn't changed. If you test extensions across both Burp Suite Professional and Community Edition, there are some changes you should be aware of. See the Creating Burp extensions documentation for details.
