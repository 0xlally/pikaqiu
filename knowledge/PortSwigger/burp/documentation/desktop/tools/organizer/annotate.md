Annotating Organizer items

June 18, 2026

Read time:

1 Minute

You can annotate Organizer items using status, highlights, and notes to add context to messages. This helps you stay organized as you work.

Statuses in Organizer

Statuses enable you to quickly see which saved requests still need attention and which ones you have already tested. Combined with filtering, this helps you focus on active work and easily return to items later.

The following statuses are available:

New

In progress

Postponed

Done

Ignored

To update message status:

Select one or more messages.

Right-click and select Status.

Choose a status from the list.

Highlighting in Organizer

Highlighting lets you visually mark messages so they stand out while browsing. It is useful for flagging requests you want to return to or quickly distinguishing important items from the rest.

To highlight messages:

Select one or more messages.

Right-click and select Highlight.

Choose a highlight color from the list.

Notes in Organizer

Notes let you record context directly on a message, such as observations, partial findings, or reminders you want to return to later.

Notes and highlights are included with messages when they are sent between Burp tools.

To add or update notes:

Select one or more messages.

Right-click and select Add notes.

Add or edit the note.
