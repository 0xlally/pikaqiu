Managing custom actions

Read time:

1 Minute

Once you've created or loaded a custom action, it's added to the Custom actions side panel. Custom actions are available from any Repeater tab.

You can perform the following actions on custom actions in the side panel:

Run - Run custom actions manually or configure them to run automatically after a response has been received. For more information, see

Running custom actions.

Edit - Click beside the custom action you want to edit.

Rename - Right-click the custom action, then select Rename.

Save a custom action to your library - Right-click the custom action, then select Save to library to store it in your Bambda library. This is your personal collection of reusable scripts.

Save a copy of a custom action to your library - Right-click the custom action, then select Save copy to library. A copy of the custom action is saved to your library. This replaces the original custom action in the Custom actions panel.

Remove from list - Right-click a custom action that is saved in your library, then select Remove from list. The custom action is removed from the Custom actions side panel but remains in your library for future use.

Delete - Right-click a custom action that isn't saved in your library, then select Delete. This permanently removes the custom action.
