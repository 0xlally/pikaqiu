Loading custom actions from your library

Your Bambda library is your personal collection of reusable scripts. You can load custom action scripts from your Bambda library into the Custom actions side panel to use in Burp Repeater.

Note

If your library doesn't contain any custom actions yet, you can download community-created scripts from our GitHub repository, then import them into your library. This enables you to use and adapt scripts created by others.

For more information, see Importing scripts into your Bambda library.

To load a custom action from your Bambda library:

In Repeater, click Custom actions to open the Custom actions side panel.

Click Load.

Select a recent custom action script from the list.

If the script you want to load isn't in the list, click View all to view all scripts stored in your library.

Select a custom action script.

Click Load.

If the custom action is error-free, it's added to the Custom actions side panel, ready for use.

Burp displays any errors in the Compilation errors panel of the Custom actions editor. You'll need to fix these before you can add the custom action to the Custom actions side panel. For more information, see Troubleshooting scripts.
