Once you've created or loaded a custom action, it's added to the Custom actions side panel. Custom actions are available from any Repeater tab.

You can run custom actions manually or configure them to run automatically:

Run - Click to run the custom action manually.

Auto-run on send - Click to enable auto-run. The custom action runs when Burp receives a response to a request sent from that Repeater tab.

Custom action output is shown in the Output panel. To clear the output, click Clear.

Running AI-powered custom actions

Custom actions can include advanced AI features, enabling real-time analysis and context-aware responses. All AI interactions are securely handled through PortSwigger's AI platform.

To run AI-powered custom actions:

Make sure you have enabled AI in Burp. To do this, go to Settings > AI and select Enable AI features.

Make sure you have sufficient AI credits. Costs vary depending on the number and complexity of the AI requests needed. You can buy AI credits from your

PortSwigger account and check your balance by clicking the AI icon in the bottom-right corner of Burp.
