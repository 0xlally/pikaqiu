Filtering Burp Logger

You can choose which types of items Logger captures and displays. This enables you to focus your work on interesting messages, and control how much memory Logger uses.

There are two types of filter in Logger:

Capture filter - Use this to control which types of items Logger captures. Items that aren't

captured will be discarded from Logger. Burp can't retrieve these items even if the capture filter is

removed.

View filter - Use this to control which captured items Logger displays. Items that are not

displayed because of view filter settings can be viewed by removing the view filter.

You can set filters using predefined options, or create advanced filters using scripts.
