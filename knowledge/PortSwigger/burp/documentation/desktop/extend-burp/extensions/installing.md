You can install extensions in Burp Suite in the following ways:

From the BApp Store - Browse and install community-created extensions directly in Burp with a single click.

Manually from a file - If you're working offline and can't access the BApp Store, or you're using a custom extension, you can install extensions manually from a file.

Related pages

If you can't access the BApp Store and you're not intentionally working offline, see our troubleshooting guide.
