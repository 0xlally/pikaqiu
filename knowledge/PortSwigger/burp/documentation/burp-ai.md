Burp AI adds AI-powered features to Burp Suite that help security teams find and validate vulnerabilities more effectively. Burp AI features are available in both Burp Suite Professional and Burp Suite DAST, tailored to each product's testing workflows.

Burp AI by product

Burp Suite Professional

Burp Suite Professional includes AI features designed to support manual penetration testing workflows. These include tools for analyzing and crafting HTTP requests, autonomously investigating scan findings, explaining vulnerabilities, and automating authentication setup.

Burp AI in Burp Suite DAST

Burp Suite DAST includes AI features designed for enterprise-scale automated scanning. These help you triage vulnerabilities faster by automatically validating scan findings, and simplify scan setup by generating authentication sequences automatically.

Security and privacy

We've designed Burp AI features with security, privacy, and transparency in mind:

Full user control - AI features only run when you choose, giving you full control over when and where they execute.

Data privacy - AI request data is processed securely through our trusted AI infrastructure. It is never stored by our AI providers.

Industry-standard security - Burp AI complies with ISO 27001 standards and implements robust encryption, ensuring data is protected in transit and at rest.

For more information on PortSwigger's security philosophy, and related documentation, see the PortSwigger Trust Center.
