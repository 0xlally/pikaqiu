Depending on your subscription, you have several different options for hosting your Burp Suite DAST instance.

If you haven't purchased a subscription yet, see Burp Suite DAST: Pricing.

If you want to set up a Cloud instance of Burp Suite DAST, see Setting up a Cloud instance.

If you want to migrate from your Linux self-hosted instance, see Migrating from Linux to Cloud

If you want to migrate from your Windows self-hosted instance, see Migrating from Windows to Cloud

If you want to deploy a self-hosted instance of Burp Suite DAST, see Setting up a self-hosted instance.

If you've already set up Burp Suite DAST and you want to learn more about how to use it, see the User guide.
