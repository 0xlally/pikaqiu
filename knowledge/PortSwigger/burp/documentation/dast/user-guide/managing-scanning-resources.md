In Burp Suite DAST, the term "scanning resources" refers to the systems that your scans run on. The type of scanning resource available to you depends on how you deployed your instance.

If you have a Cloud instance of Burp Suite DAST, see Using self-hosted scanning machines with a Cloud instance.

If you have a self-hosted instance of Burp Suite DAST, see Managing scanning resources for a self-hosted instance.
