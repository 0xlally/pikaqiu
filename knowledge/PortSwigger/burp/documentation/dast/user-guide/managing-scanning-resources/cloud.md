Cloud

This section explains how to use a self-hosted scanning machine with your Cloud instance of Burp Suite DAST.

You can install a self-hosted scanning machine on your own infrastructure. This enables you to run scans locally, in order to scan internal applications that can't be accessed from outside your network.

You can still use Burp Suite DAST to manage scans by your self-hosted scanning machines, and the scan results are still displayed on the dashboard.

Note

These instructions only apply to Cloud instances of Burp Suite DAST. If you have a self-hosted instance and want to deploy additional scanning machines, see Deploying additional scanning machines.
