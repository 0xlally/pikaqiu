In Burp Suite DAST, the term "site" refers to either a web app or API that you want to scan.

To scan a site, you first need to add it to Burp Suite DAST. Most data and configuration options in Burp Suite DAST are managed on a per-site basis. Adding detailed information about your sites unlocks the full potential of Burp Suite DAST's analytics features, enabling you to track issues with your site more effectively over time.

To add a site for scanning web apps, see Scanning web apps

To add a site for scanning APIs, see Scanning APIs
