The settings menu contains shortcuts to several of the configuration menus used in Burp Suite DAST. To access the settings menu, click the symbol in the top-right corner of the window. Choose from the following options:

Burp AI - enable Burp AI features for your instance of Burp Suite DAST.

Scanning machines - configure scanning machines and scanning pools.

Scan configurations - manage built-in and custom scan configurations.

Extensions - add or edit extensions to implement custom scan behaviors and capabilities.

Email - configure an SMTP server to enable email notifications.

Updates - manage updates for standard instances.

Licensing - review your current license, or upload a new license key.

Network - configure your network settings.

Integrations - integrate Burp Suite DAST with your CI/CD platform.

Integrations - integrate Burp Suite DAST with your issue tracking platform.

Integrations - integrate Burp Suite DAST with Slack.

Issue management - configure the default false positive, accepted risk, and edited issue severity

settings for scans.

Site and scan data - configure how sites and the data generated by scans are handled.

User activity logs - enable and download user activity logs.

Database backup - configure database backups.

Miscellaneous - submit usage data about Burp Suite DAST.
