After you install the application, you need to use the Burp Suite DAST web interface to set up the admin user:

On the Create admin user page, enter the Email address and Password for the admin user.

Confirm your password and click Finish & login.

The application displays the Sign in page.

Warning

Make sure you store your password somewhere secure.

You can now sign in and begin using Burp Suite DAST. When you log in to Burp Suite DAST for the first time, you are prompted to activate your license.
