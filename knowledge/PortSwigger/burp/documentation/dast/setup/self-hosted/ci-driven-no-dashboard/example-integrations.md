To help you integrate with some of the most popular CI platforms, we've created some platform-specific integration examples for CI-driven scans with no dashboard. These guides explain how to add the CI-driven scan command and configuration YAML file to your pipeline script.

Note

You can integrate and configure CI-driven scans with any CI platform that supports containers. The platforms in these examples do not provide any additional functionality over other platforms.

For a non-platform specific integration guide, see Running your first CI-driven scan with no dashboard.
