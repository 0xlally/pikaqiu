California Polytechnic State University

Burp Suite DAST in the education sector.

Introduction

California Polytechnic State University (or Cal Poly) was founded in 1901. Serving over 21,000 students annually, and with six colleges, it features in Forbes' list of the Top 25 Schools in the West.

Cal Poly purchased Burp Suite DAST because the software enables its teams to automate

security scanning. This automation, says its CISO, allows its AppSec team to deliver more security where it's needed.

Use case

Burp Suite DAST is valuable to Cal Poly, because it allows it to:

Free its AppSec team to spend time where it's most valuable.

Reduce risk by gaining greater security coverage across its web portfolio.

Shift left and integrate security into the software development lifecycle.

Key features

Burp Suite DAST has a number of key features Cal Poly relies on:

Dashboard and scan summary reports for full visibility of their entire web portfolio at a glance.

Customizable scan configurations - which allow flexibility in security testing.

increase its use of Burp Suite DAST."
