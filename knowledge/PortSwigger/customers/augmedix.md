Customer case study

Augmedix

Burp Suite Professional in the healthcare sector.

Introduction

Augmedix is a medium-sized enterprise in the healthcare sector. It aims to help clinicians better focus on patient care. This is accomplished through the use of technology.

The healthcare sector is known for its stringent compliance requirements. Augmedix describes its operational and technological infrastructure as

going "beyond HIPAA compliance".

Key benefits

Burp Suite Professional is important to Augmedix for a number of reasons. It allows Augmedix to:

Reduce the risk of data breaches.

Secure the software it relies on to run its business.

Secure the software / services it sells to customers - thus ensuring uptime and maintaining customer trust.

Make penetration testing processes efficient.

Be compliant.

Key features

Burp Suite Professional has a number of key features that are used by Augmedix:

Burp Intruder, to automate customized attacks.

Burp Scanner, to automate searching for bugs.

Burp Suite extensions, to customize workflows.

The wide array of manual tools Burp Suite Professional puts in one product.

"Without Burp rest of the pentest seems to me pointless,

because you cannot verify the vulnerabilities in most cases without Burp."

Challenges

Augmedix purchased Burp Suite Professional to allow its application security engineers to test its own web applications.

"Resources

like PortSwigger Research and the Web Security Academy mean PortSwigger are the experts I'd recommend to anyone wanting to expand their cybersecurity capabilities."

Benefits

Augmedix finds that it gains a number of benefits from using Burp Suite Professional:

They are able to discover harder to find vulnerabilities.

They are able to speed up penetration testing.

It has all the features they need in one product.

PortSwigger are web security experts and Augmedix know their toolkit can catch critical bugs.

PortSwigger supports its users - both directly and through the vibrant Burp Suite user community.

"97% of surveyed organizations are likely to recommend Burp Suite Professional."

Value statements

Azizur Rahman - an application security engineer at Augmedix - strongly agreed with the following statements:

I perform my job more effectively by using Burp Suite.

Burp Suite's scanning technology helps me catch more vulnerabilities faster.

Burp Suite is great value for money.

Without Burp Suite we'd need additional pentesting resources.

Burp Suite is "best in class" software.

Final thoughts

Augmedix had the following to share on its experience with Burp Suite Professional:

Beyond pure product functionality, access to the Burp Suite user community and PortSwigger team was very important in their decision to choose Burp Suite.

Given that Burp Scanner detects the latest web vulnerability types discovered by PortSwigger Research, it has been critical to their ability to catch vulnerabilities that they cannot with other tools.
