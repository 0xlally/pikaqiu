This extension can be used to help test for certain categories of

vulnerabilities, including XSS and SQL injection.

To use, select an HTTP request, and choose "Send to Sentinel" from the

context menu. Sentinel will then issue various requests, with attack patterns inserted.

It will analyze the resulting HTTP responses to try to find vulnerabilities.
