Streamline the process of documenting vulnerabilities in penetration tests and security assessments. By simplifying the copying of HTTP requests and responses, it allows you to focus more on testing than documentation, ultimately improving workflow efficiency.

Features

Copy entire request & response

Copy entire request & response headers.

Copy entire request & response headers + selected response data.

Usage

Use the appropriate keyboard shortcut or right-click and choose from the context menu to copy the request and response.

Switch to your reporting tool (e.g., Word, Markdown, Web App, LaTeX Editor, etc.).

Paste the copied request or response into your report.

Optionally, add context to explain the request or response.

This process significantly reduces the need for manual copying and pasting, enhancing your overall productivity during report generation.

Configuration

The extension can be configured directly in Burp's settings menu to customize the text clipping features and keyboard shortcuts.
