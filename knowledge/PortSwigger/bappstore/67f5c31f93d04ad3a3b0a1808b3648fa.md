This extension stores requests and responses from selected Burp tools in an ElasticSearch index

including metadata like headers and parameters.

This enables a Burp user to

perform extended searches, such as "POST requests where parameter csrftoken is not

set" or "Responses with missing header x-content-type-options".

See blog

article for further details.
