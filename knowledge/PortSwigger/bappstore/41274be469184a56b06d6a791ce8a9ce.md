Extensibility Helper (formerly known as "BCheck Helper") streamlines the process of discovering and importing BChecks and Bambda snippets by loading them from a remote GitHub or local Git repository. Scripts can be filtered by keyword or tag and either copied to the clipboard or saved to disk for use within Burp Suite.

The extension adds a tab titled "Extensibility Helper", with three sub-tabs:

"BCheck Store" - displays available BChecks

"Bambda Store" - displays available Bambdas

"Settings" - provides configuration options

Features

Search and filter BChecks and Bambdas by name, author, description, or tags

Import items directly into Burp

Copy scripts to clipboard or save to file

Bulk export and import supported

Supports GitHub and local Git repositories

Customizable repository and export settings

Persistent configuration between sessions

Optional logging for script operations

Usage

Finding Scripts

Use the search bar in the "BCheck Store" or "Bambda Store" tab to locate scripts by keyword. Results are shown in a filterable table with name, description, and tags.

Importing a BCheck

Direct Import

Select a BCheck from the table

Click "Import"

The BCheck will appear in the BCheck table, enabled by default

Clipboard Import

Select a BCheck

Click "Copy to Clipboard"

Go to "Extensions" -> "BChecks"

Click "New" -> "Blank"

Paste into the editor and click "Save"

File Import

Click "Save to file"

Go to "Extensions" -> "BChecks"

Click "Import" and select the saved file

Enable the BCheck if needed

Bulk Import

Apply filters if desired

Click "Save all items to disk"

Go to "Extensions" -> "BChecks"

Click "Import" and select the export directory

Enable the BChecks if needed

Importing a Bambda

Direct Import (v2025.4+)

Select a Bambda from the table

Click "Import"

The Bambda will appear in the Bambda Library table

Note: A direct import will overwrite any existing Bambdas with the same UUID.

Clipboard Import

Select a Bambda

Click "Copy to Clipboard"

Go to "Extensions" -> "Bambda library"

Click "New" -> "Blank"

Paste into the editor and click "Save"

File Import

Click "Save to file"

Go to "Extensions" -> "Bambda library"

Click "Import" and select the saved file

Bulk Import

Apply filters if desired

Click "Save all items to disk"

Go to "Extensions" -> "Bambda library"

Click "Import" and select the export directory

Configuration

Export Paths: Set default save locations for BChecks and Bambdas in the "Settings" tab.

Repository Selection: Choose between "GitHub" and "Filesystem" sources for BChecks and Bambdas. Configure the repository URL or local path accordingly.

Custom GitHub Repos: Update the repository name and URL. If private, supply an API key. Click "Refresh" to reload scripts.

Logging: Enable logging in the "Settings" tab to display download and unpacking details.
