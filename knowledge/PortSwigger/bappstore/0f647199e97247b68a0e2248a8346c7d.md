JWT Monitor

This extension monitors a provided JWT token for expiration and

automatically replaces any existing JWT tokens in outgoing requests

with the monitored one. It also includes an autopilot mode that

intelligently pauses task execution when the JWT token is about to

expire and resumes automatically when a new token with sufficient

validity is provided.

Features

Monitors JWT token expiration with real-time countdown

display

Automatically replaces existing JWT tokens in Authorization

headers and cookies

Autopilot mode that pauses task execution when token expires

within one minute

Automatic task resumption when new JWT token with at least three

minutes validity is supplied

Visual expiration warnings with color-coded status

indicators

Displays decoded JWT header, payload, and signature in formatted

JSON

Comprehensive logging of token replacements and task control

actions

Usage

Navigate to the JWT Monitor tab in the extension interface

Paste your JWT token into the token input field

Click the Apply button to start monitoring the token

The extension will display the token's expiration countdown and

decoded components

All outgoing requests will automatically have their JWT tokens

replaced with your monitored token

To enable autopilot mode, click the Autopilot toggle button

When autopilot is enabled, task execution will pause when the

token has less than one minute remaining and resume automatically when

a new token with at least three minutes validity is provided

Monitor the log area for real-time updates on token replacements

and task control actions

The extension supports JWT tokens in both Authorization headers

(Bearer format) and cookies,

automatically detecting and replacing tokens that begin with eyJ.
