Proxy Auto Config

This extension automatically configures Burp upstream proxies to match desktop proxy settings. This includes support for Proxy Auto-Config (PAC) scripts.

It uses Proxy Vole to detect the proxy settings. PAC scripts are executed within a sandbox.
