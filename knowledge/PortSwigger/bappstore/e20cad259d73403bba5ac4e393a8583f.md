Description

This extension augments Intruder to probe endpoints

consuming Java serialized objects to identify classes,

libraries, and library versions on remote Java classpaths.

Usage

Send your request to Intruder, highlight the payload

position of your serialized object, and add a wordlist of Java

class names to look for.

Add the custom intruder payload processor via "Invoke Burp

Extension->Classname to GadgetProbe" to convert your

payload string (e.g.,

"org.apache.commons.collections.functors.invokertransformer")

to a Java serialized object probe.

Run the Intruder attack. The results will be sent back via

DNS interactions to a Collaborator instance managed by the

extension.

View the results in the GadgetProbe tab.

Use the "Detect Library Versions" button to detect version

signatures on supported libraries (use the "Copy

Detect Library Wordlist" button to copy the list to your

clipboard).

For more details and wordlists, check out the project on

GitHub
