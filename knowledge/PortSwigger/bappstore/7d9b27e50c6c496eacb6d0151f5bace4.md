As pentesters we all had at least one test where we all needed to use Base64 Image converters online which took an extra efort of copying things and sometimes we were running out of time.

Captcha Converter makes that process easy.

If your response contains a JSON object with image data, a new tab will be added to your response editor.

The new tab will display the rendered image and response data.
