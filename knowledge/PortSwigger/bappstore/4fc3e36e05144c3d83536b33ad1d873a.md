WebSocket History Exporter streamlines the process of exporting WebSocket communications by providing a dedicated

interface for selecting, configuring, and saving WebSocket message history to structured file formats. The extension

integrates seamlessly with the WebSocket History view, enabling rapid documentation and analysis of real-time web

application communications.

Features

Context menu integration for direct selection from WebSocket History

Dual export format support with XML and JSON output options

Customizable message direction labeling for client-to-server and server-to-client communications

Optional timestamp inclusion with precise millisecond formatting

Dedicated configuration tab for export settings management

Structured data output including message content, direction, timestamps, and source URLs

Usage

Navigate to "Proxy → WebSockets History" to view captured WebSocket communications

Select the desired WebSocket messages for export

Right-click and choose "Extensions → WebSocket History Exporter → Send to WSX"

Switch to the WSX tab to configure export settings

Customize client-to-server and server-to-client labels as needed

Enable timestamp inclusion if required for analysis

Select XML or JSON format based on your preferred data structure

Use Browse... to specify the export file location

Click Export Messages to generate the formatted export file
