Warning: some users have reported high memory and CPU usage when running the extension on large audits.

This extension passively scans requests looking for values containing hashes

using common algorithms (SHA, MD5, etc.). Observed hashes are reported to the

user.

Additionally, the extension keeps track of submitted parameter values, such

as usernames, email addresses, and ID numbers. When a hash of a previously

submitted value is identified, this is also reported to the user.

Here is a brief video that explains the concept: https://youtu.be/KdgeipzmESE.

Requires Java version 8
