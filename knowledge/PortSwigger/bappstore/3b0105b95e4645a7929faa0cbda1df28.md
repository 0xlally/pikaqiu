The Qualys WAS extension connects Burp with the Qualys Web Application Scanning (WAS) module on the Qualys Cloud

Platform. It lets you import a WAS finding into Repeater to manually validate a scanner-discovered vulnerability,

and send Burp Scanner issues to Qualys WAS so you can view and report them alongside WAS findings for a more

complete picture of your web application's security posture. A Qualys WAS subscription with API access is required.

Features

Import a Qualys WAS finding into Repeater by finding ID or by browsing a web app's open findings, then replay

the request to confirm the vulnerability.

Send selected scanner issues to Qualys WAS directly from the issue context menu, with the option to purge or

close existing Burp issues in WAS.

Supports all Qualys shared platforms (US, EU, Canada, India) as well as private cloud platforms.

Usage

On the Qualys WAS tab, select the platform for your subscription, enter your Qualys username and password, and

click Validate Credentials to confirm connectivity.

To validate a finding, right-click in the Repeater request area and choose Import Qualys WAS Finding.

Choose Enter Finding ID to fetch a known finding (the longer UUID is preferred), or Select from a Web App's Open

Findings to browse open vulnerabilities for a chosen web app, then pick a payload if multiple are present.

Click Import Request, update any transient authentication token such as a session cookie if needed, then send

the request and inspect the response.

To export issues, run passive and/or active scans, then open Target → Site map → Issues.

Right-click the desired scanner issues, choose Send to Qualys WAS, select the target web application, set the

purge or close option as needed, and confirm.
