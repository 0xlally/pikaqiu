This extension integrates Burp with Pentest-Tools.com, enabling penetration testers to send audit issues

directly to their Pentest-Tools.com workspaces with a right-click. It streamlines vulnerability management by

allowing testers to triage findings and maintain organized testing projects without leaving their manual testing

workflow.

To learn more about Pentest-Tools.com web & network vulnerability scanning

features and integrations, go to the integrations page at https://pentest-tools.com/features/integrations.

Features

Send single or multiple audit issues to Pentest-Tools.com workspaces via the context menu

Automatic workspace synchronization with API token-based authentication

Maps Burp issue metadata including severity, confidence, target details, and remediation guidance

Dedicated GUI tab for API key management and workspace selection

Usage

Navigate to the Pentest-Tools.com tab

Enter your Pentest-Tools.com API key and click Save

Select your desired workspace from the dropdown menu

Right-click on any audit issue(s) and select "Extensions → Pentest-Tools.com → Send issues to

[workspace_name]"

Review the success or error messages displayed, or check the log section in the Pentest-Tools.com tab
