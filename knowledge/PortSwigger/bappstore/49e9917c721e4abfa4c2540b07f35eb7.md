WebSphere Portlet State Decoder

This extension displays the decoded XML state of a WebSphere Portlet in a new tab when the request is viewed.

Upon clicking the tab, the extension makes a request against an endpoint on the application server which decodes the URL, formats the resulting XML, and displays it in the tab.
