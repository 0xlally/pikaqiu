The JSON Escaper Burp Suite plugin simplifies the process of escaping JSON payloads for pentesters.

It eliminates the need for manual escaping and ensures proper formatting for testing.

With its simple interface, the plugin enables you to enter your payload, escape it, and display the result in a JTextArea where you can select and copy the text
