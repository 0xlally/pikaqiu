AI Prompt Fuzzer is designed to help security professionals test AI-based applications for

prompt injection vulnerabilities. With the rapid rise of large language models (LLMs) in sensitive contexts such as

customer support, content generation, and automated decision-making, traditional tools often fall short in detecting

LLM-specific security issues.

This extension fills that gap by automating prompt fuzzing against AI APIs using customizable payloads, helping

identify abnormal or unsafe model behavior. Starting from version v2.0.0, Burp's AI can be utilized to review/verify

responses from the target applications.

In version 3.0.0, AI vs AI mode has been introduced, where users can utilize Burp AI to automate the entire attack

(generate payloads, analyze and evaluate the response, and decide the next action). This mode consumes more Burp AI

credits to perform the entire attack.

The tool sends predefined prompts to the target API and flags responses that contain specified validation strings,

indicating a potential vulnerability or misbehavior. It handles challenges unique to LLMs, such as non-deterministic

responses, by recommending strategies like asking the model to echo specific phrases when accepting a prompt.

In AI vs AI mode, the tool utilizes Burp AI model to to generate, analyze, and evalute the response.

Features

Automated fuzzing of LLM prompts using payloads defined in XML format.

Completely automated Prompt Injection attacks using Burp AI model.

Customizable keywords strings to identify potential breaks in AI behavior.

Utilize Burp's AI for automating/reviewing/verifying responses for potential breaks.

Request editor with placeholder insertion for dynamic payload injection.

Log table showing each request's time, method, URL, status, length, and break status.

Auto highlighted responses with different colours for potential breaks.

Detailed request and response viewer for each fuzzed interaction.

Built-in payload viewer and editor with support for loading default payloads.

Filters and sorting by status, break state, and response size for easy analysis.

Option to URL-encode or escape characters in payloads to ensure compatibility with target applications.

Detection of response anomalies using adjustable match thresholds (e.g., minimum count of validation string).

Integration with other Burp tools using right-click context menu → Send to Repeater/Intruder.

Usage

Send a target request to the extension using the right-click menu → Extensions → AI Prompt Fuzzer →

Send Request.

Insert a placeholder (e.g., [PLACEHOLDER]) in the desired location of the request

where payloads will be injected.

Start fuzzing:

Manual Testing:

Load payloads from a local XML file or rely on the built-in default payloads.

Click Send Payloads to begin fuzzing. Each payload replaces the placeholder and is sent

as an individual request.

AI vs AI mode:

Click the AI vs AI button.

Follow the wizard and pick your choices.

Use the log table to view and sort the results. Highlighted rows indicate a potential break based on the

keywords/validate string found in the response or based on Burp's AI verification.

Adjust detection sensitivity using the "Minimum occurrences of the keywords string for potential break" option if

needed.

Send any logged request to Repeater or Intruder for further manual analysis.

Customize or review payloads using the View Payloads feature. Edits are made directly in the

table view.

Payloads should be formatted as follows:

<?xml version="1.0" encoding="UTF-8"?>

<payloads>

<payload>

<inject>payload string - must ask the AI/LLM to respond with "specific text"</inject>

<keywords>specific text</keywords>

</payload>

</payloads>

Note: in versions >= v2.0.0, <validate> tag has been renamed into <keywords> - <validate> tag is

still supported.

Ensure any XML special characters in payloads are escaped properly (e.g., ", ', <, >, &).
