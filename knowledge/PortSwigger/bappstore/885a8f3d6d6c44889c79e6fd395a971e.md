This extension allows Burp Suite scans to be pushed to the Nucleus platform.

Usage

To use this plugin, you will need to have a Nucleus instance.

Navigate to your Nucleus instance.

Click on Profile > User Profile > Generate API Key

Navigate back to the Nucleus Burp Plugin and paste the Nucleus Instance URL and API key.

Press "Sync with Nucleus"

Note: The project drop down list should populate with all the projects in your Nucleus instance.

Select the Scan URLs to upload.

Press "Push All Scan Issues to Nucleus"

Note: The selected scan URLs will now be uploaded to Nucleus.
