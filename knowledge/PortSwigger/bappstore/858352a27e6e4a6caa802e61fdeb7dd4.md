This Burp extension reads metadata from various filetypes (JPEG, PNG, PDF, DOC, XLS and much more) using ExifTool.

Results are presented as Passive scan issues and Message editor tabs.

Windows, Linux and macOS binaries (12.25) are embedded into the extension. Another versions can by used by putting them in the system path.
