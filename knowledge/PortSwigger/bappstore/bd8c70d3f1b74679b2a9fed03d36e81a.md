Protobuf Decoder

This extension decodes and beautifies protobuf responses.

When a new protobuf response is detected (based on the "Content-Type:

application/x-protobuf" header), a custom tab appears in Burp's message editor

showing the decoded response.

In addition, a .proto file can be used to define the message format.

This extension requires Jython version 2.7 or later.
