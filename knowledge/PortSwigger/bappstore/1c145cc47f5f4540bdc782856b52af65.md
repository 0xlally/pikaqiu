Hotpatch provides a way to hook into key functions using custom scripts written in Python or JavaScript. Scripts can

modify requests and responses, handle session management, process payloads, and automate repetitive tasks through

the Montoya API.

Features

Write scripts in Python or JavaScript with a built-in syntax highlighting editor

Enable multiple scripts simultaneously with configurable execution order

Implement handlers for HTTP requests/responses, proxy interception, session handling, intruder payload

processing, and context menu actions

Share variables between scripts for coordinated automation

Usage

Navigate to the Hotpatch tab and create a new script by selecting the script type (Utility, HTTP Handler, Proxy

Handler, Session Handling Action, Payload Processor, or Context Menu Action)

Write your script using the Python or JavaScript editor, with access to the Montoya API

Enable the script and configure the execution order if using multiple scripts

Monitor script execution and review any errors in the STDOUT/STDERR output panels
