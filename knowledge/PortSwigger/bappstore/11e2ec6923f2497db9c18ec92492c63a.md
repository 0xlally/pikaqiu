This extension allows you to perform on-demand Yara scans of websites within the Burp interface based on custom Yara rules that you write or obtain.

Example use cases include scanning spidered sites for obfuscated Javascript or any other specific string patterns of interest present in

any part of a request or response. It has been tested with Yara 3.4 on Windows 7 and 10, and Kali 2.0.

Requires the latest version of the standalone Yara binary (3.4) for your OS. Instructions at:

https://github.com/plusvic/yara/releases/tag/v3.4.0.

Requires Jython version 2.7 or later.
